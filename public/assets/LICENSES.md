# Asset-Lizenzen

Jede Datei unter `public/assets` muss hier stehen. Fremde Dateien nur mit klarer Lizenz eintragen (Quelle, Lizenz, Autor). Das Repository ist oeffentlich.

Platzhalter werden von `npm run assets:placeholders` erzeugt (`scripts/generate-placeholders.mjs`). Wird eine Datei ersetzt, hier die Herkunft anpassen.
