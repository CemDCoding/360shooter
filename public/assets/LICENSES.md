# Asset-Lizenzen

Jede Datei unter `public/assets` muss hier stehen. Fremde Dateien nur mit klarer Lizenz eintragen (Quelle, Lizenz, Autor). Das Repository ist oeffentlich.

Die Sprites entstehen aus den Pixeldaten des Designers mit `npm run sprites:build`. Nur die Töne sind Platzhalter, sie werden von `npm run assets:placeholders` erzeugt (`scripts/generate-placeholders.mjs`). Wird eine Datei ersetzt, hier die Herkunft anpassen.
